# Đề 24: Hệ thống Quản lý Công việc (Task Tracker)

## Khởi chạy hệ thống
1. Chạy ứng dụng web & CSDL:
   `docker compose up -d`
2. Chạy stack giám sát & log:
   `docker compose -f monitoring/docker-compose.monitoring.yml up -d`

## Địa chỉ truy cập:
- Website Task Tracker: http://localhost
- pgAdmin Tool: http://localhost:5050
- Grafana: http://localhost:30000
- Prometheus: http://localhost:9090
